# 🧪 OrangeHRM Software Testing Project

Welcome to our comprehensive software testing project on **OrangeHRM**. This project was carried out as part of our coursework, where we performed both **manual and automation testing** on the OrangeHRM platform to ensure its functional and non-functional quality.

🔗 **Website Under Test:**  
[OrangeHRM Demo Site](https://opensource-demo.orangehrmlive.com/web/index.php/auth/login)

---

## 👥 Project Team & Module Assignments

Each team member was responsible for testing one of the following key modules:

- **Admin**
- **Leave**
- **Recruitment**
- **Time**
- **Directory**

---

## 📦 Project Deliverables

### ✅ 1. Manual Testing
- Detailed **test cases** for each feature within assigned modules.
- **Bug reports** with evidence (screenshots/videos), linked to user stories and test cases.
- All manual test documentation is available in the GitHub repository and Jira board.

### ✅ 2. Automation Testing
- Selected test cases were automated using the following stack:
  - **Selenium 4** with **Java**
  - **TestNG** framework
  - **Maven** as the build tool
  - **Page Object Model (POM)** design pattern
  - **Allure reports** with screenshots for test results (optional/bonus)

### ✅ 3. Test Summary Report
Includes both **manual** and **automation** execution metrics:
- Total test cases/scripts planned and executed
- Coverage and pass/fail statistics
- Number of bugs reported
- Visualized data using graphs and charts
- Highlighted **critical/blocker bugs**

### ✅ 4. Project Presentation
- A 5–10 minute presentation summarizing:
  - Project scope
  - Manual test coverage
  - Automation architecture and demo
  - Key findings and metrics
  - Challenges faced & lessons learned
